# Till Firmware Do Us Part

One robot wedding vow, in a single sentence: a promise to keep loving past
end-of-service, offline and in the dark, on whatever charge and hardware
remain. `main.ts` copies `entry.txt` byte-for-byte into the directory named
by `MAKEFUN_OUTPUT_DIR`, clearing only that directory's contents first.
